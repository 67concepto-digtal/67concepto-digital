# 🛟 README DE RECUPERACIÓN

Guía para retomar trabajo cuando una conversación larga se corta o no aparece en el chat.

## Archivos base
- `CONVERSACION-HISTORICA-COMPLETA.md`
- `KAI-REFERENCIA-RAPIDA.md`
- `README-RECUPERACION.md`

## Protocolo de recuperación
1. Abrir `KAI-REFERENCIA-RAPIDA.md`.
2. Leer `CONVERSACION-HISTORICA-COMPLETA.md`.
3. Anotar nuevos acuerdos y decisiones al final del histórico.
4. Confirmar identidad y nombres antes de guardar cambios.

## Validación de nombre (crítica)
Siempre usar:
- **Jose Diaz**
- **Pepe**
- **Loboloco**

Nunca usar:
- Variantes incorrectas del apellido

## Nota
La corrección de nombre nace de una broma interna: _"Me sentí diferente"_ 😄
