## 📋 REGLAS DEL CENTRO

```
REGLA 1: TODO DOCUMENTADO
├─ Información sin documentación = no existe
├─ Cada idea, decisión, hallazgo → documento
└─ = CONTINUIDAD GARANTIZADA

REGLA 2: SIN DUPLICACIÓN
├─ Si existe en 15-CII → no duplicar
├─ Referenciar en lugar de copiar
├─ Links entre documentos
└─ = EFICIENCIA

REGLA 3: DECISIONES REGISTRADAS
├─ Cada decisión importante → documento
├─ Incluir contexto, alternativas, justificación
├─ Responsable identificado
└─ = CONTEXTO HISTÓRICO

REGLA 4: JUSTIFICACIÓN DE FEATURES
├─ Todo nuevo módulo → su justificación
├─ Debe trackearse a idea/análisis
├─ ¿Por qué? Documentado
└─ = INNOVACIÓN INTELIGENTE

REGLA 5: ALINEACIÓN MISIONAL
├─ Toda innovación → alineada con misión 67-AI
├─ Pregunta: ¿Sirve a PYME?
├─ Si no → descartamos
└─ = ENFOQUE CLARO

REGLA 6: RESPONDER SIEMPRE
├─ Toda idea/feature → responder:
│  ├─ ¿Genera valor para cliente?
│  ├─ ¿Fortalece visión empresa?
│  ├─ ¿Es diferenciador?
│  └─ ¿Merece tiempo/recursos?
└─ = DECISIONES FUNDADAS

REGLA 7: ACCESO CONTROLADO
├─ CII = CONFIDENCIAL
├─ Solo equipo dirección (ahora)
├─ Futuro: Equipo autorizado
└─ = VENTAJA COMPETITIVA PROTEGIDA

REGLA 8: ACTUALIZACIÓN REGULAR
├─ Revisión semanal: Inteligencia competitiva
├─ Revisión mensual: Tecnologías, tendencias
├─ Revisión quincenal: Ideas nuevas
├─ Revisión continua: Decisiones
└─ = VIVO, NO MUERTO
```
