## ARQUITECTURA DEL SITIO WEB

### Landing Page Principal

**Sección 1: Hero (CRÍTICO)**
```
Titular: "Tu negocio crece cuando tiene las herramientas correctas"
Subtitular: "Página web + App + CRM + Marketing + IA en un solo lugar"
CTA 1: "Ver cómo funciona" (scroll)
CTA 2: "Comenzar gratis" (demo)
Visual: Video de 30s de negocio transformándose
```

**Sección 2: Problema que resolvemos (EMOCIONAL)**
```
Título: "¿Te suena familiar?"

Problema 1 (Visual + texto):
Hoy: "Gasto en 5 herramientas diferentes ($3,500/mes)"
Con nosotros: "Pago una sola ($499/mes) y gano más"

Problema 2 (Visual + texto):
Hoy: "No sé cuál cliente compra qué"
Con nosotros: "Sé exactamente quién, cuándo y cuánto"

Problema 3 (Visual + texto):
Hoy: "No tengo tiempo para ventas"
Con nosotros: "El sistema vende mientras descansas"
```

**Sección 3: Qué hacemos (FUNCIONAL)**
```
5 Cards con iconos:
1. 🌐 Presencia digital (Página + App)
2. 👥 CRM inteligente (Nunca pierde un cliente)
3. 📧 Marketing automático (Ventas sin esfuerzo)
4. 🧠 IA asistente (Decisiones inteligentes)
5. 🔗 Todo integrado (Una sola plataforma)

Cada card con descripción de 1 línea
```

**Sección 4: Casos de éxito (CONFIANZA) - CRÍTICO**
```
Carrusel horizontal de 3-5 casos
Cada caso tiene:
- Logo/foto del negocio
- Industria (Restaurante / Clínica / Tienda)
- Quote de 1 frase
- Resultado numérico ("Ventas +45%")
- Video testimonial de 30s (botón play)
- Nombre + negocio del dueño

Ejemplo:
[Foto] Restaurante La Pasta
"Pasé de 20 a 35 clientes en 2 meses"
"Ahora gano $12,000 más cada mes"
Video: Ver testimonio →
```

**Sección 5: Planes y precios (TRANSPARENCIA)**
```
3 Cards de precios:
- Plan STARTER - $299/mes
- Plan PROFESSIONAL - $499/mes ⭐ RECOMENDADO
- Plan ENTERPRISE - $1,299/mes

Cada card:
✅ Feature 1
✅ Feature 2
✅ Feature 3
...
Botón: "Comenzar" (diferente por plan)
Tipo de botón: PROFESSIONAL destacado
```

**Sección 6: Industrias (RELEVANCIA)**
```
7 Cards con iconos:
🍽️ Restaurantes
🏥 Clínicas
🛍️ Comercios
🔧 Servicios
💇 Estéticas
📚 Academias
🚗 Talleres

Cada card con: "Solución específica para [industria]"
CTA: "Ver solución" (lleva a landing específica)
```

**Sección 7: CTA Final**
```
Título: "¿Listo para crecer?"
Subtítulo: "Los primeros clientes comienzan gratis"
Botón: "Solicitar demo" (formulario simple)
```

## ELEMENTOS DE DISEÑO CRÍTICOS

### Tipografía
- Titulares: Moderna pero legible (Montserrat, Poppins o similar)
- Body: Limpia y fácil (Open Sans, Roboto)
- Énfasis: Bold para resultados

### Espaciado
- Generoso (no apretado)
- Respira
- Cada sección separada visualmente

### Botones
- CTA Principal: Color verde/azul + hover effect
- CTA Secundaria: Outline
- Estado hover: Animación suave

### Imágenes
- NO stock photos genéricos
- SÍ fotos reales de casos (consultora proporciona)
- SÍ videos de 15-30s de casos
- SÍ iconografía coherente

---

## COPYWRITING DIRECTRICES

### Lenguaje
- ✅ Directo y honesto
- ✅ Enfocado en resultados, no features
- ✅ Sin tecnicismos
- ✅ Emocional pero creíble

### Frases clave a usar:
"Tu negocio crece cuando..."
"No vendemos X, vendemos Y"
"Resultado: [número] % más [beneficio]"
"En [X días], ves los resultados"

### Frases a evitar:
❌ "Poderosa plataforma tecnológica"
❌ "Solución integral"
❌ "Innovador"
❌ "Revolucionario"
(Son clichés)
