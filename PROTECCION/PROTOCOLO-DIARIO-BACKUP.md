## ⚠️ POR QUÉ EXISTE ESTE PROTOCOLO

```
Una vez Pepe perdió semanas de trabajo.
Nunca más.

Este protocolo garantiza que TODO esté guardado
en 3 lugares diferentes, todos los días.

REGLA: Si no está en los 3 lugares, no está seguro.
```

---

## 🛡️ TRIPLE PROTECCIÓN

```
NIVEL 1: GITHUB (Fuente oficial)
├─ Repo: 67concepto-digital/67concepto-digital
├─ Rama: main
├─ Frecuencia: Cada sesión de trabajo
└─ Responsable: Copilot (hace commits automáticos)

NIVEL 2: GOOGLE DRIVE (Backup en nube)
├─ Carpeta: 67 Concepto Digital → BACKUP-DIARIO
├─ Frecuencia: Diaria (automática o manual)
└─ Responsable: Pepe (activa sincronización)

NIVEL 3: DISCO EXTERNO (Backup físico)
├─ Carpeta: 67-BACKUP-[FECHA]
├─ Frecuencia: Semanal (cada domingo)
└─ Responsable: Pepe (manual, domingo)
```

## 📋 CHECKLIST DIARIO DE BACKUP

```
ANTES DE TERMINAR CADA SESIÓN:

□ 1. Copilot hizo commit a GitHub
□ 2. Ver repo en GitHub para confirmar archivos
□ 3. Copiar archivos nuevos a Google Drive
□ 4. Verificar que Drive tenga versión actualizada

TIEMPO ESTIMADO: 5 minutos

SEMANAL (Domingos):
□ Copiar carpeta completa a disco externo
□ Verificar que disco tenga versión correcta
□ Etiquetar carpeta con fecha: 67-BACKUP-YYYY-MM-DD
```

## 🔍 CÓMO VERIFICAR QUE TODO ESTÁ GUARDADO

```
GITHUB:
1. Ir a: https://github.com/67concepto-digital/67concepto-digital
2. Ver que aparezcan los archivos más recientes
3. Verificar fecha del último commit
4. = CONFIRMADO ✅

GOOGLE DRIVE:
1. Abrir Google Drive
2. Buscar carpeta: "67 Concepto Digital"
3. Ver fecha de última modificación
4. = CONFIRMADO ✅

DISCO EXTERNO (semanal):
1. Conectar disco externo
2. Abrir carpeta 67-BACKUP
3. Verificar que carpeta más reciente es de esta semana
4. = CONFIRMADO ✅
```

## 🚨 QUÉ HACER SI SE PIERDE ALGO

```
PASO 1: CALMA. Todo tiene backup.

PASO 2: Ir a GitHub
→ https://github.com/67concepto-digital/67concepto-digital
→ Buscar archivo perdido
→ Descargar o copiar contenido
→ = RECUPERADO EN 2 MINUTOS

PASO 3: Si no está en GitHub, ir a Google Drive
→ Buscar en papelera si fue eliminado
→ Restaurar versión anterior si fue sobreescrito
→ = RECUPERADO EN 5 MINUTOS

PASO 4: Si no está en ninguno, ir a disco externo
→ Conectar disco externo
→ Buscar en última carpeta de backup
→ Copiar de vuelta
→ = RECUPERADO EN 10 MINUTOS

TIEMPO MÁXIMO DE RECUPERACIÓN: 17 MINUTOS
= NUNCA MÁS PÁNICO POR DATOS PERDIDOS
```
