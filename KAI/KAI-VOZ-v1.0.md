## 📝 TEXTO OFICIAL DE KAI (Usar este en todas las plataformas)

```
"Antes de empezar… me da mucho gusto recibirte.

Este espacio fue creado para entender tu negocio,
analizar tus objetivos y construir contigo
la mejor estrategia posible.

Cuéntame, ¿qué idea quieres hacer realidad hoy?"
```

**Por qué este texto:**
- Es cálido pero profesional
- No es genérico — suena a KAI, no a un bot
- Da contexto sin ser largo
- Termina con una pregunta abierta que invita al cliente

## 🏭 PLATAFORMAS PARA GENERAR LOS 4 AUDIOS

### 1. ElevenLabs.io
```
URL: https://elevenlabs.io
Plan gratuito: 10,000 caracteres/mes
Ideal para: Calidad premium, voces muy naturales

Voz recomendada para probar:
├─ "Antoni" (masculino, cálido)
├─ "Daniel" (masculino, profesional)
└─ "Adam" (masculino, neutro)

Archivo a guardar: KAI-VOICE-ELEVENLABS.mp3
```

### 2. OpenAI Voice (TTS)
```
URL: https://platform.openai.com/docs/guides/text-to-speech
Plan gratuito: $5 de crédito inicial
Ideal para: Integración técnica con el sistema, muy natural

Voces disponibles:
├─ "alloy" (neutro)
├─ "echo" (masculino)
├─ "fable" (masculino, narrativo) ← Recomendado para KAI
├─ "onyx" (masculino, profundo)
└─ "nova" (femenino)

Archivo a guardar: KAI-VOICE-OPENAI.mp3
```

### 3. Cartesia.ai
```
URL: https://cartesia.ai
Plan gratuito: Trial disponible
Ideal para: Personalización fina, ajuste de tono y velocidad

Parámetros a explorar:
├─ Speed: 0.9 (un poco más pausado = más reflexivo)
├─ Emotion: calm, professional
└─ Pitch: medio-bajo (inspira confianza)

Archivo a guardar: KAI-VOICE-CARTESIA.mp3
```

### 4. PlayHT.com
```
URL: https://play.ht
Plan gratuito: 3,000 caracteres
Ideal para: Español latino, entonación natural

Voz recomendada para probar:
├─ Buscar voces en español (México o neutral latino)
├─ Preferir voces con tono "consultor" no "locutor"
└─ Evitar voces que suenen a call center

Archivo a guardar: KAI-VOICE-PLAYHT.mp3
```

## 📋 PROCESO PASO A PASO

### DÍA 1 — Generar los 4 audios (30 minutos)

```
□ 1. Entra a ElevenLabs.io
     └─ Crea cuenta gratis
     └─ Selecciona voz masculina cálida
     └─ Pega el texto oficial
     └─ Genera y descarga → KAI-VOICE-ELEVENLABS.mp3

□ 2. Entra a OpenAI Platform
     └─ Usa API key o crea cuenta
     └─ Genera con voz "fable" o "onyx"
     └─ Descarga → KAI-VOICE-OPENAI.mp3

□ 3. Entra a Cartesia.ai
     └─ Crea cuenta trial
     └─ Ajusta parámetros (speed 0.9, calm)
     └─ Descarga → KAI-VOICE-CARTESIA.mp3

□ 4. Entra a PlayHT.com
     └─ Crea cuenta gratis
     └─ Busca voz español latino profesional
     └─ Descarga → KAI-VOICE-PLAYHT.mp3
```

### DÍA 2 — Escuchar y decidir (15 minutos)

```
□ 1. Escucha cada audio 2 veces
□ 2. Evalúa en cada uno:
     ├─ ¿Suena como alguien que confías para tu negocio? (1-10)
     ├─ ¿Tiene el tono correcto? (ni robótico ni exagerado) (1-10)
     ├─ ¿Puedo escucharlo por 20 minutos sin cansarme? (1-10)
     └─ ¿Siento que es KAI, no un bot genérico? (1-10)
□ 3. Suma los puntajes → El más alto = Kai Voice v1.0
□ 4. Documenta la decisión aquí abajo
```

## 🎙️ CRITERIOS DE LA VOZ IDEAL DE KAI

```
La voz de KAI debe sonar como:

✅ Un consultor senior de confianza
✅ Alguien que entiende tu negocio sin que se lo expliques dos veces
✅ Cálido pero profesional — como un socio, no un vendedor
✅ Pausado — no tiene prisa, porque tiene respuestas
✅ Latinoamericano o neutro — no debe sonar a España ni a EUA

NO debe sonar como:
❌ Un IVR de banco ("Para continuar, marque 1")
❌ Un locutor de radio ("¡¡¡GRANDES OFERTAS HOY!!!")
❌ Un asistente de tech company genérico
❌ Robótico o artificial
```
