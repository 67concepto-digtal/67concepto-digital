## 🔐 PASO 1: PREPARAR DISCO EXTERNO

### OPCIÓN A: Encriptación con VeraCrypt (MÁXIMA SEGURIDAD)

```
PASO 1: Descargar VeraCrypt
├─ Ir a: veracrypt.fr
├─ Descargar versión tu SO (Windows/Mac)
├─ Instalar (siguiente, siguiente, siguiente)
├─ Ejecutar VeraCrypt
└─ Tiempo: 5 minutos

PASO 2: Crear volumen encriptado
├─ Abre VeraCrypt
├─ Click: "Create Volume"
├─ Opción: "Create a container file"
├─ Click: Next
└─ Tiempo: 2 minutos

PASO 3: Seleccionar disco externo
├─ Click: "Select File"
├─ Navega a: [Tu disco externo]
├─ Nombre: "67_CONCEPTO_BACKUP"
├─ Formato: .hc (VeraCrypt)
├─ Ubicación: Raíz de disco
└─ Tiempo: 1 minuto

Ejemplo ruta:
└─ D:\67_CONCEPTO_BACKUP.hc (Windows)
└─ /Volumes/MyDrive/67_CONCEPTO_BACKUP.hc (Mac)

PASO 4: Configurar encriptación
├─ Encryption algorithm: AES-256
├─ Hash algorithm: SHA-512
├─ Filesystem: NTFS (compatible)
├─ Tamaño: 500GB (usa lo que necesites)
└─ Click: Next

PASO 5: Crear contraseña
├─ Contraseña: SUPER FUERTE
│  └─ Mínimo: 20 caracteres
│  └─ Incluir: Mayúsculas + números + símbolos
│  └─ Ejemplo: "67Concepto!@#$%2026ABC"
│
├─ Confirmar: Repetir contraseña
├─ PIM: Dejar vacío (avanzado)
├─ Click: Next
└─ ⚠️ SI OLVIDAS = PÉRDIDA TOTAL DATOS

GUARDAR CONTRASEÑA:
├─ NO en email
├─ NO en Google Keep
├─ SÍ en papel (guardar físico)
├─ SÍ en caja fuerte
├─ SÍ memorizar
└─ SÚPER importante (no hay recuperación)

PASO 6: Generar volumen
├─ Mover mouse aleatoriamente (seguridad)
├─ Esperar: 2-5 minutos (según tamaño)
├─ Progreso: Barra de avance
├─ Terminó: "Volume successfully created"
└─ Click: Exit

RESULTADO:
├─ Archivo: 67_CONCEPTO_BACKUP.hc (encriptado)
├─ En disco: D:\67_CONCEPTO_BACKUP.hc
├─ Tamaño: 500GB (vacío, crece con datos)
├─ Acceso: Solo con contraseña
└─ Seguridad: Nivel gobierno 🔐
```
